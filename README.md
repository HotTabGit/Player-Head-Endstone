# Player Heads для Endstone

При убийстве игрока выпадает его голова. На предмете есть ник жертвы и описание. Голову можно поставить или надеть. Для поддерживаемого скина плагин сам готовит пакеты и подключает их к миру при запуске.

## Установка

1. Останови Endstone. Скачай [Player Heads 1.2.3](https://github.com/HotTabGit/Player-Head-Endstone/releases/download/v1.2.3/endstone_player_heads-1.2.3-py3-none-any.whl) и положи файл в папку `plugins`.
2. При обновлении убери старый `.whl`. Сохрани папку `plugins/player_heads` с ключом и данными голов.
3. Запусти сервер. Настройки появятся в `plugins/player_heads/config.toml`.

Целевая связка — Endstone 0.11.15, Bedrock 26.60 и Python 3.12 на Windows или Linux. Нужен `online-mode=true`. Новые скины появляются после перезапуска. Игроку нужен ресурспак сервера. Если папка нового мира ещё не существовала при первом запуске, перезапусти сервер ещё раз.

При снятии подписанной головы плагин выдаёт предмет сам. Проверь это в творческом режиме и на серверах с правилами выпадения или защитой блоков.

## Команды

- `/heads status` — посмотреть состояние.
- `/heads give [ник]` — выдать голову онлайн-игрока. Без ника выдаёт свою.
- `/heads reload` — перечитать настройки.

Право `player_heads.admin` по умолчанию у операторов.
